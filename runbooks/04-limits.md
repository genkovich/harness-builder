# 04. Межі: max_turns, max_cost, обрізання

[Усі етапи](README.md) · [Попередній](03-tools.md) · [Наступний](05-failures.md)

**Гілка:** `step-04`. Перейти: `npm run step 04`, далі перезапусти `npm run web`.

## Що додаємо і навіщо

Коли модель застрягла, зупиняє її код. Замість константи `maxTurns: 10` зʼявляється тип `Limits` з типовими значеннями: 8 кроків на задачу, бюджет $0.05, до 6000 символів у результаті тула, 1000 токенів відповіді. Кроки й бюджет можна перебити з `.env` через `MAX_TURNS` і `MAX_COST_USD`.

Коли ліміт спрацював, харнес пише подію `limit` і зупиняється з причиною `max_turns` або `max_cost`. Користувач отримує чесне «Задача може бути незавершена», і в trace видно, що саме спрацювало.

Третя межа стосується результату тула. `searchNotes` з порожнім запитом повертає всі нотатки чату, і через місяць їх може бути кілька сотень. Довгий результат обрізаємо всередині, а саме повідомлення `tool_result` лишається на місці, з тим самим `toolCallId`. Пара виклик-результат ціла завжди.

## Код

### Ліміти: `src/harness.ts`

```ts
export const defaultLimits: Limits = {
  maxTurns: 8,
  maxCostUsd: 0.05,
  maxToolChars: 6_000,
  maxOutputTokens: 1_000,
};

// Порожні значення з .env не перебивають типові ліміти.
export function withDefaults(custom: Partial<Limits> = {}): Limits {
  const set = Object.entries(custom).filter(([, value]) => value !== undefined);
  return { ...defaultLimits, ...Object.fromEntries(set) };
}
```

У `src/agent.ts` ліміти читаються з `.env`: `Number(process.env.MAX_TURNS) || undefined`. Порожня змінна дає `undefined`, і лишається типове значення. Ліміти, з якими пішла задача, видно в події `start`.

### Бюджет перевіряємо після кожного кроку

```ts
if (cost !== null && cost > limits.maxCostUsd) {
  trace('limit', { kind: 'max_cost', value: limits.maxCostUsd, actual: cost });
  return stop('max_cost', `Зупинився на бюджеті $${limits.maxCostUsd}. Задача може бути незавершена.`);
}
```

`cost` = `null`, якщо ціни моделі немає. Тоді бюджет не працює взагалі: харнес не знає, скільки витратив.

### Обрізання результату тула

```ts
// Обрізаємо вміст результату, а не викидаємо повідомлення: пара виклик-результат лишається цілою.
function clip(output: JSONValue, maxChars: number) {
  const json = JSON.stringify(output) ?? 'null';
  if (json.length <= maxChars) {
    return { value: output, chars: json.length, truncated: false };
  }
  return {
    value: {
      truncated: true,
      preview: json.slice(0, maxChars),
      note: `Результат обрізано: ${maxChars} з ${json.length} символів. Звузь запит, щоб отримати решту.`,
    },
    chars: json.length,
    truncated: true,
  };
}
```

Модель бачить, що результат обрізано, на скільки, і що робити далі: звузити запит. Для `searchNotes` це означає шукати за словом замість «покажи все».

## Спробуй

Ліміти простіше побачити, якщо їх зменшити. Додай у `.env` і перезапусти `npm run web`:

```bash
MAX_TURNS=2
```

Попроси «Запамʼятай три речі окремими нотатками: реліз у пʼятницю, купити каву, дзвінок з Петром». Якщо модель зберігає по одній нотатці за крок, після другого кроку буде «Спрацював ліміт» з підписом «Цикл зупиняє код харнесу, не модель», а зупинка «ліміт кроків». Прибери `MAX_TURNS`, коли надивишся.

Бюджет на Groq Free не спрацює ніколи: ціна там нуль, і витрати весь час нуль. Щоб побачити `max_cost`, потрібна модель з ціною. Типовий бюджет $0.05 на короткій задачі теж не вичерпаєш, тож поріг ставимо крихітний, щоб його перебив уже перший крок. На `openai/gpt-4.1-mini`:

```bash
MAX_COST_USD=0.00005
```

Або задай вигадану ціну прямо на Groq. З нею перший крок коштує приблизно $0.0003:

```bash
PRICE=1,0.5,2
MAX_COST_USD=0.0001
```

Після кожної зміни `.env` зупини `npm run web` (Ctrl+C) і запусти знову: `.env` читається лише на старті.

Бюджет харнес перевіряє після кроку з викликом тула. Тож проси щось, де модель піде в тул, наприклад «Покажи всі мої нотатки». Після першого ж кроку буде «Спрацював ліміт», зупинка «бюджет» і текст «Зупинився на бюджеті $0.0001. Задача може бути незавершена.» Лічильник «вартість / бюджет» угорі покаже, скільки витрачено проти ліміту. Прибери `MAX_COST_USD` і `PRICE`, коли надивишся, і знову перезапусти.

Обрізання видно на `searchNotes`, коли нотаток багато. Руками набирати їх довго, тож допиши сорок штук в окремий чат `bulk`. Команда додає їх до наявних, твої нотатки з інших чатів, як-от реліз з етапу 02, лишаються на місці:

```bash
node -e "const fs=require('node:fs');const f='.data/notes.json';const old=fs.existsSync(f)?JSON.parse(fs.readFileSync(f,'utf8')):[];fs.writeFileSync(f,JSON.stringify([...old,...Array.from({length:40},(_,i)=>({id:'demo-'+i,chatId:'bulk',text:'Нотатка '+i+': '+'деталі '.repeat(20),createdAt:new Date().toISOString()}))],null,2))"
```

Запускай її з кореня репо, коли `.data/` уже є: вона зʼявляється з першим запуском `npm run web`. Тепер у веб-чаті впиши в поле `chat id` значення `bulk` і попроси «Покажи всі мої нотатки». Результат `searchNotes` важить приблизно 9 300 символів при межі 6000. На «Результат» буде бейдж з розміром до обрізання, наприклад «9 341 символів», і позначка «обрізано». Модель має сказати, що бачить лише частину.

## Перевірка

```bash
npm test -- --step 04
```

- `04 max_turns: модель, що ніколи не зупиняється, зупиняє код`: з `maxTurns: 3` рівно три запити і подія `limit`.
- `04 max_cost: бюджет задачі в доларах`: один дорогий крок, і харнес зупиняється з `max_cost`.
- `04 searchNotes по всіх нотатках обрізається, пара виклик-результат лишається`: 30 нотаток, `maxToolChars: 500`, `preview` рівно 500 символів, у наступному запиті є і id виклику, і «Результат обрізано».

## Якщо не так

- `MAX_TURNS` чи `MAX_COST_USD` не діє: `.env` читається лише на старті, зупини й перезапусти `npm run web`. Нуль і порожнє значення означають «типове».
- Бюджет не спрацьовує: перевір, що в моделі є ціна. Якщо вартість «н/д», харнес грошей не рахує. Ще одна причина: модель відповіла одразу, без тула. Бюджет перевіряється лише після кроку з тулом.
- Модель після обрізаного результату знову просить усі нотатки: підкажи в задачі слово для пошуку, наприклад «покажи нотатки про реліз».
- Згенеровані нотатки не видно: перевір, що в полі `chat id` стоїть саме `bulk`.
- Команда посіву падає з `ENOENT`: теки `.data/` ще немає. Запусти раз `npm run web` або зроби `mkdir .data`.
